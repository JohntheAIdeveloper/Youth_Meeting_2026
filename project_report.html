1. Executive Summary

The JTLM Youth Meeting 2026 Web Portal is a modern, high-performance web application designed and built for the upcoming annual youth convention organized by இயேசுவே மெய்யான ஒளி ஊழியங்கள் (Jesus the True Light Ministries) on 20 October 2026.

The web platform fulfills a vital communication mission: to mobilize youth from across Tamil Nadu, provide clear event information, present the keynote speakers with dignity, deliver interactive directions to the venue, and enable instantaneous registration via Google Forms.

Key Objectives Delivered
  • Official Ministry Brand Integrity: Extracted, cleaned, and embedded the official Jesus the True Light Ministries emblem across Navbar, Footer, Favicon, and Open Graph cards with zero image distortion.
  • High-Speed Registration Engine: Embedded and direct Google Forms integration with mobile-optimized tap targets, enabling attendees to sign up in under 30 seconds.
  • Studio Portrait Showcase: High-resolution studio portraits of keynote speakers (Pr. Anthony David and Dr. A. Vanaja, Psychologist) displayed in circular badges with dual-ring gold accents.
  • Geospatial Navigation: Resolved official Google Maps destination coordinates (11.361147, 77.703681) with embedded interactive map and native Google Maps directions button.
  • Dual-Cloud High Availability: Redundant deployment across Vercel Edge Network and GitHub Pages CDN ensuring 100% continuous uptime.

3. Technical Architecture & Technology Stack

The web portal is engineered as a modern Single-Page Application (SPA) prioritizing zero runtime overhead, instant First Contentful Paint (FCP), and deterministic production builds.

Layer Technology Engineering Rationale & Benefit
Framework React 19 (SPA) Declarative components, fast virtual DOM reconciliation, smooth modals.
Language TypeScript 5.x / 7.x Strict static typing eliminates runtime bugs and guarantees config integrity.
Bundler Vite 8.x + ESBuild Extremely fast compilation (1.27s production build) and tree-shaking.
Styling Tailwind CSS 3.4 Utility-first responsive design; only 17.6 kB gzipped CSS shipped in production.
Typography Anek Tamil & Mukta Malar Self-hosted Fontsource packages preventing external layout shifts and network blocking.
Icons Lucide React Tree-shaken SVG icons; lightweight, crisp, and high-contrast on mobile displays.
Config Pattern Single Source of Truth Central configuration in src/config/event.ts for zero-drift maintenance.

Component Topology Hierarchy

App.tsx (Root Application Container) ├── Navbar.tsx (Sticky Header, Ministry Emblem, Navigation Links) ├── HeroSection.tsx (Theme Headline "வாலிபனே எழும்பிப் பிரகாசி!", Date Badge, CTAs) ├── CountdownTimer.tsx (Real-time dynamic Days / Hours / Minutes / Seconds calculation) ├── AboutSection.tsx (Mission statement, spiritual focus, ministry background) ├── EventDetails.tsx (Keynote Speakers Showcase, Program Schedule, Food Notice) ├── PosterSection.tsx (Official Poster v3 with QR Code & Lightbox Zoom Modal) ├── LocationSection.tsx (Interactive Google Maps Embed, Destination Pin, Directions) ├── RegistrationModal.tsx (Google Forms iframe embed with fallback new-tab link) └── Footer.tsx (Official Emblem, Credits, Direct Emergency Phone Links)

Centralized Configuration Architecture (src/config/event.ts)

The entire application strictly isolates event facts from presentation components. Component files never contain hardcoded dates, phone numbers, or URLs; they read exclusively from the strongly typed eventConfig object:

// src/config/event.ts excerpt: export const GOOGLE_FORM_URL = 'https://forms.gle/69quUsz8yt7kqCgj8'; export const GOOGLE_MAPS_URL = 'https://maps.app.goo.gl/8YqJ9DueV8WkDSeJ8'; export const GOOGLE_MAPS_EMBED_URL = 'https://www.google.com/maps?q=11.361147,77.703681&z=16&hl=en&output=embed'; export const eventConfig = { ministry: { ta: 'இயேசுவே மெய்யான ஒளி ஊழியங்கள்', en: 'Jesus the True Light Ministries' }, title: { ta: 'வாலிபர் கூடுகை', en: 'Youth Meeting – 2026' }, theme: { ta: 'வாலிபனே எழும்பிப் பிரகாசி!', en: 'Young Man, Arise and Shine!' }, date: { dayNumber: '20', monthTa: 'அக்டோபர்', year: '2026', iso: '2026-10-20' }, time: { ta: 'காலை 10 மணி முதல் மதியம் 1 மணி வரை', en: '10:00 AM – 1:00 PM' }, food: { ta: 'மதிய உணவு வழங்கப்படும்', en: 'Lunch will be provided.' }, } as const;

5. End-to-End Implementation Workflow

The project followed a structured six-milestone engineering roadmap from asset processing to multi-cloud deployment:

1
Official Ministry Branding & Logo Vectorization
Extracted official ministry emblem from checkered background. Generated clean transparent RGBA PNG and WebP formats (logo.png, logo-tight.png, favicon.png). Integrated across sticky Navbar, Footer, and Open Graph metadata without distortion.
2
Geospatial Venue Resolution & Interactive Map Embed
Resolved official Google Maps shortlink (maps.app.goo.gl/8YqJ9DueV8WkDSeJ8) to precise GPS coordinates 11.361147, 77.703681. Integrated responsive zero-API-key Google Maps iframe embed paired with native Google Maps navigation trigger.
3
Official Poster v3 with QR Code & Lightbox Viewer
Integrated finalized official poster containing event schedule, theme typography, and embedded registration QR code. Configured cache-busted asset paths (poster-v3.webp) and responsive lightbox modal with zoom and download capabilities.
4
Cross-Platform Packaging & Vercel Linux Architecture Fix
Diagnosed and resolved Vercel build container EBADPLATFORM failure for Rollup/Rolldown binary packages. Configured package.json optionalDependencies alongside vercel.json install parameter --include=optional, ensuring clean Linux server builds.
5
Dual-Remote Git Orchestration & Multi-Cloud Deployment
Connected repository to two remote endpoints: origin (Youth_Meeting_2026.git for GitHub Pages) and jtlm (jtlm_youth_meeting_2026.git for Vercel). Pushed synchronized commits and deployed to both platforms with automated build triggers.

  • Zero Server Secrets in Git: The client application contains zero private keys or server secrets; all configuration is bundled safely via Vite.
